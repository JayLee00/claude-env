위 대화는 예시입니다. HUD 네 줄은 실제 claude-hud에 예시 세션 값을 넣어 렌더링한 결과입니다.

4메모리로컬 PC RAM 사용량 (showMemoryUsage). 학습·시뮬레이션과 같이 돌릴 때 봅니다.

자주 하는 일

말 한 줄로 시작해서 Claude가 절차를 끝까지 밟습니다. 올리기와 push 같은 바깥으로 나가는 단계는 확인을 받고 진행합니다.

읽은 논문 공유

> graspium 올려줘
  1. 발표자료 PPT를 PDF로 inbox에 넣기만 함
  2. 슬라이드를 읽고 arXiv에서 제목·저자 확인
  3. 분야, 키워드, TL;DR, 썸네일 쪽을 채우고 dry-run
  4. 확인 후 Graspium 사이트에 카드로 push
  5. 같은 논문을 연구 노트 볼트에도 정리

연구 노트 볼트 '재뇌투'

> 재뇌투에 넣어줘
  1. 논문 원문 PDF를 받아 원문 기준으로 노트 작성
  2. 내 슬라이드 정리는 '내 정리' 섹션에 따로
  3. 매일 쓰고 있는 원고 주제에 맞춰 논문 추천

회로와 부품

> 이 보드 주문 전에 봐줘
  1. KiCad 회로도·PCB에서 전원 트리, DRC/ERC, DFM 점검
  2. 데이터시트에서 핀·사양 확인
  3. 부품 재고·가격 비교, BOM과 JLCPCB 파일 준비

로봇 코드와 실험

> ssh로 Linux PC에서 돌려줘
  1. Franka FR3 · 로봇손 제어, 원격조작 코드 수정
  2. 수집한 데이터 정리와 학습 작업
  3. 결과를 GitHub 레포로 커밋·push
